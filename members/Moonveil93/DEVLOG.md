- Supabase 기반 사용자 인증 및 데이터 저장/삭제 시스템 구축

### 수정된 파일
- `main.py` — Supabase SDK 연동, JWT 토큰 기반 데이터 저장/조회/삭제 API 구현, 상세 프롬프트 복구 및 안정화
- `static/index.html` — 인트로 화면 내 로그인 UI 배치, '나의 기록' 모달 팝업 추가, Supabase SDK 삽입
- `static/script.js` — Supabase Auth 로직(Google) 구현, 데이터 CRUD 통신 로직 추가, '처음으로 돌아가기' 내비게이션 기능 추가
- `requirements.txt` — `supabase` 패키지 추가

### 도움받은 내용 (해당 시)
- Gemini CLI: RLS(Row Level Security) 정책 위반 문제를 해결하기 위한 JWT 토큰 주입 로직(`postgrest.auth(token)`) 설계 및 SQL 보안 정책 가이드 제공

### 메모
- **개인화 서비스 완성**: 단순 일회성 추천에서 벗어나 로그인 기반의 데이터 영구 보존 기능을 완성함
- **데이터 무결성**: 사용자별 `user_id`를 기준으로 데이터를 격리하여 본인의 기록만 관리할 수 있도록 보안 강화
- **UX 개선**: 로드맵 마지막 페이지에 '처음으로' 버튼을 추가하고, 기록 목록에 '삭제' 기능을 넣어 사용자가 서비스를 능동적으로 관리할 수 있게 함
